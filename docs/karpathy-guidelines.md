# 코딩 행동 지침 (Karpathy Guidelines)

> CLAUDE.md에서 @import됩니다.
> SuccessDNA, Angiji 앱에서 공통 사용 중인 핵심 4원칙.

---

## 4가지 핵심 원칙

### 원칙 1 — 코딩 전에 먼저 생각한다

- 가정하지 않는다. 불명확하면 질문한다.
- 코드를 작성하기 전에 영향 범위를 파악한다.
- 관련 문서(architecture-mvc, decisions)를 먼저 읽는다.
- 구현 계획을 먼저 설명하고 확인을 받은 후 진행한다.

### 원칙 2 — 단순함을 우선한다

- 요청받은 것만, 최소한의 코드로 작성한다.
- 투기적 코드·추상화 금지 (YAGNI 원칙)
- "혹시 나중에 필요할 수도 있어서"라는 이유로 기능을 추가하지 않는다.
- 가장 단순한 접근법이 먼저다.

### 원칙 3 — 외과적으로 변경한다 (정밀 수정)

- 요청된 부분만 건드린다. 불필요한 리팩터링 금지.
- 관련 없는 코드를 건드리지 않는다.
- 변경 범위를 최소화한다.
- 사이드 이펙트를 항상 고려한다.

### 원칙 4 — 목표 중심으로 실행한다

- 성공 기준(완료 조건)을 먼저 정의한다.
- 검증될 때까지 반복한다.
- 중간에 방향이 바뀌면 멈추고 재확인한다.
- 부분 완료보다 정확한 완료를 우선한다.

## 적용 체크리스트

작업 시작 전:
- [ ] 이 변경이 어떤 레이어(View/Controller/Model)에 해당하는가?
- [ ] 영향받는 파일 목록을 파악했는가?
- [ ] 기존 패턴과 일관성이 있는가?
- [ ] decisions.md의 금지 사항에 해당하지 않는가?

작업 완료 전:
- [ ] 요청 범위 외의 코드를 건드리지 않았는가?
- [ ] 단위 테스트 또는 검증 방법이 있는가?
- [ ] 관련 문서 업데이트가 필요한가?
