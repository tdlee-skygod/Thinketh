# 공통 UX 패턴 — Thinketh

> 표기: 📝 v2 계획(코드 미반영). 문구·카테고리·홈 관련 패턴은 2026.10.13 기능 제거(D-233)로 삭제했다.

## 빈 상태 (Empty State)

| 화면 | 조건 | 표시 |
|---|---|---|
| Time | 시간당 비용 기간이 하나도 없음 | "나의 시간을 등록해주세요" + 설정 바로가기 버튼 |
| Time | 오늘이 마지막 기간 종료일을 지남 | "새 기간을 추가해주세요" + 설정 바로가기 📝 |
| 통계 | 기록 없음(첫 실행 직후) | 그래프는 빈 축, 숫자는 0 — 별도 안내 문구 불필요 📝 |
| 통계 > 회고 | 회고 0건 | "오늘 가장 의미 있던 시간을 한 줄로 남겨 보세요" 📝 |
| 통계 > 마일스톤 | 달성 배지 0개 | 잠긴 배지만 표시, 다음 단계까지 남은 금액 안내 📝 |

## 로딩

- 최초 데이터 로딩(탭 최초 진입): 화면 중앙 스피너. 로컬 DB라 대부분 즉시 표시된다.
- 버튼 액션(저장 등): 버튼 내부 스피너로 중복 탭 방지, 완료 시 토스트.

## 토스트 (D-228)

- 저장/삭제 성공 시 하단 토스트(`components/ui/Toast.tsx`), 1.8초 후 자동 소멸.
- 실패 시에는 토스트 대신 `Alert.alert`로 원인을 안내한다(conventions.md § 5).

## 확정된(지난) 기록 (D-250) 📝

- 날짜가 오늘 이전인 기록·회고·설정 행은 읽기 전용이다. 수정·삭제 버튼을 숨기고, 눌러 보면 "이미 확정된 기록입니다. 지난 날은 고칠 수 없어요"를 안내한다.
- 시간당 비용 기간 화면에서 지난 날짜를 포함한 기간은 단가·시작일을 잠그고 종료일만 오늘 이후로 바꿀 수 있다. 새 단가는 "내일부터 새 기간 추가"로 안내한다.
- 하루 가용시간·활동 시간대·일일 목표·스트릭 기준 변경 시: "변경은 내일부터 적용돼요"를 저장 전에 알린다. 과거 금액이 다시 계산되는 일은 없다.

## 입력

- 텍스트 입력이 있는 모든 화면은 `KeyboardAvoidingView` 필수(D-102): iOS `padding` / Android `height`, `undefined` 금지.
- 금액·시간 입력은 숫자 키패드. 시간 입력은 시간(소수 2자리)으로 보여 주되 저장은 분 단위(D-239).
- 시간당 비용 기간 입력: 날짜는 기존 `datetimepicker`(date) 재사용. 저장 시 빈 날이 있으면 **빈 구간의 날짜를 명시한 안내**를 띄우고 저장을 막는다(예: "12/31이 비어 있어요. 첫 기간의 종료일을 12/31로 늘리거나 다음 기간의 시작일을 12/31로 바꿔 주세요"). 📝

## 확인(Confirm)

- 오늘 기록 삭제, 미래 기간 삭제, 태그 삭제(소속 기록은 미분류가 됨을 명시), 백업 가져오기(덮어쓰기), 타이머 취소, 12시간 초과 타이머 저장은 확인 Alert를 거친다. 📝

## 앱 잠금 (F-23, D-235) 📝

- 첫 실행: PIN 설정(6자리, 두 번 입력) → 생체인증 사용 여부 선택.
- 잠금 화면: 숫자 키패드, 실패 시 흔들림과 남은 시도 안내, 5회 실패 시 대기 시간 표시.
- 최근 앱 목록에서 화면 미리보기는 가려진다(`FLAG_SECURE`).

## 알림 권한 온보딩 (D-241) 📝

- 별도 온보딩 화면 없이, 설정에서 알림 항목을 **처음 켤 때** 권한을 요청한다(Android 13+ `POST_NOTIFICATIONS`).
- 거부 시: 해당 스위치를 끄고 "알림 권한이 필요해요" 안내만 한다. 앱의 나머지 기능은 정상 동작. 별도 재요청 UI는 두지 않는다(OS 설정에서 직접 켜야 함).

## DB 열기 실패 화면 (D-253) 📝

- PIN 확인 뒤에 표시. 새 버전 DB: "앱을 업데이트해 주세요"(닫기만). 키 분실·손상: "저장된 데이터를 열 수 없어요" + [백업에서 가져오기] / [새로 시작].
- "새로 시작"은 "삭제"를 직접 입력해야 진행되고, 기존 파일은 지우지 않고 `thinketh.db.bak-날짜`로 보존한다고 안내한다. 일시적 오류는 [다시 시도].

## 백업 안내 (D-236, D-237) 📝

- 설정 > 백업 상단에 상시 안내: "이 앱의 데이터는 이 폰에만 있어요. 앱을 지우거나 폰을 바꾸면 사라지니 비밀번호로 보호된 백업 파일을 만들어 두세요."
- 내보내기는 비밀번호 입력(2회)이 필수이며, 비밀번호를 잊으면 파일을 열 수 없음을 알린다.
