# 기능 요구사항 — Thinketh

> 표기: ✅ 구현됨 / 📝 계획 확정(코드 미반영).
> ID는 코드 커밋 메시지·PR·이슈에서 참조한다 (예: `feat: 기간별 시간당 비용 (F-24)`).
> v2(2026.10.14): 앱은 **휴대폰 안에서만 동작**한다(D-234). 서버·계정 없음.

## 현재 유지되는 기능

| ID | 기능 | 설명 | 상태 | 관련 화면 |
|---|---|---|---|---|
| F-21 | Time 탭 | "나의 시간" 설정을 기준으로 남은/지난 일수·금액, 오늘 나의 시간·버려진 시간·금액을 계산해 표시. 오늘 나의 시간 라인의 연필 아이콘으로 오늘의 의미있는 일(제목/내용/시간)을 하루 여러 건 기록(합산). 숫자는 FND(7세그) 폰트. v2에서 저장소는 로컬 DB, 단가는 기간별(F-24). 화면은 스크롤 없는 한 화면 유지(남은·오늘 카드 + 스트릭 한 줄 + 타이머 버튼), "지난" 카드는 통계 탭으로 이동(D-245) | ✅(이전 저장소 기반) → 📝 로컬 전환 | (tabs)/time, modal/time-log |

## v2 신규 기능

| ID | 기능 | 설명 | 상태 | 관련 화면 |
|---|---|---|---|---|
| F-23 | 앱 잠금 ✅(빌드 검증 전) | 로그인 대체(D-235). 6자리 PIN 필수, 생체인증 선택, 백그라운드 30초 후 재잠금(설정 가능), PIN 분실 시 기기 잠금으로 재설정, 최근 앱 미리보기 가림 | 📝 | lock, settings |
| F-24 | 기간별 시간당 비용 ✅(단계 1-A, 빌드 검증 전) | 시작일·종료일·시간당 금액을 여러 기간으로 등록(D-239). 겹침 금지, **기간 사이 빈 날 금지**(저장 시 안내), 종료일 변경 시 다음 기간 자동 조정. 금액은 날짜별 단가로 계산. **지난 날짜를 포함한 기간의 단가·시작일은 수정·삭제 불가**(D-250) | 📝 | modal/time-settings |
| F-25 | 내보내기/가져오기 ✅(단계 1-B, 빌드 검증 전) | DB 전체를 **비밀번호로 암호화**한 파일로 내보내고, 검증 후 덮어쓰기/병합으로 가져옴(D-237, 병합 규칙 D-253). 유일한 백업 수단 | 📝 | modal/backup |
| F-26 | 스트릭 · 일일 목표 · 프리즈 | 하루 나의 시간 ≥ 기준(기본 1시간)이면 연속일 +1, 일일 목표(예: 2시간) 진행 막대, 주 1회 프리즈(기록에서 계산, D-242) | 📝 | (tabs)/time, settings |
| F-27 | 실시간 타이머 | "나의 시간 시작/정지"로 금액이 실시간으로 올라감. 정지 시 기록 자동 저장(태그·제목 입력). 앱을 껐다 켜도 이어짐 | 📝 | (tabs)/time, modal/timer |
| F-28 | 알림 · 오늘의 손익 | 손실 회피 알림(오전/오후/저녁), 오늘의 손익(나의 금액 − 버려진 금액). 모든 알림은 항목별 선택, 기본 꺼짐, 일반 문구(D-241) | 📝 | settings, 알림 |
| F-29 | 태그 · 복리 환산 · 통계 탭 | 활동 태그(공부/운동/개발/독서 등 사용자 정의), 태그별 비중 도넛, 이번 달 금액의 12개월 복리 환산(가정 수익률 설정 가능, 기본 연 5%), 주/월 추이, 가장 높은 요일, **누적 현황**(지난 일수·지난 나의 금액·지난 버려진 금액 — Time 탭에서 이동, D-245) | 📝 | (tabs)/stats |
| F-30 | 마일스톤 · 보상 | 누적 나의 금액 100만/300만/500만/1,000만/3,000만/1억 원 도달 시 배지·축하 화면, 사용자가 정한 보상 문구 연결. 받은 배지는 영구 유지 | 📝 | (tabs)/stats |
| F-31 | 회고 | 취침 전 알림으로 여는 한 줄 회고("오늘 가장 의미 있던 시간은?"), 하루 1건, 통계 탭에서 모아보기 | 📝 | modal/reflection, (tabs)/stats |
| F-32 | Android 위젯 | 오늘 나의 금액·스트릭·목표 달성률 표시. 표시 전용, 금액 숨김 기본, "시작" 버튼은 앱 타이머를 열기만 함(D-243). Android 전용 | 📝 | 홈 화면 |
| F-34 | 일 단위 확정 | 하루가 지나면 그날의 버려진 시간·금액 등을 확정 저장하고(앱 시작·복귀·자정 롤오버 때 실행), **지난 날의 기록·회고·설정은 수정 불가, 당일만 수정 가능**(D-250, D-251). 설정(가용시간 등) 변경은 다음 날부터 적용 | 📝 | (tabs)/time, (tabs)/stats, modal/time-log |
