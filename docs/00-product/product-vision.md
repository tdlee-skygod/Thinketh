# 제품 비전 — Thinketh

> v2(2026.10.14, D-234): **시간을 돈으로 환산해 매일 의미 있게 쓰도록 돕는 개인용 앱**이다. 아래는 v2 기준이며 구현은 단계별로 진행한다(changelog.md 참고).

## 한 줄 정의

"버려진 시간"과 "나의 시간"을 금액으로 보여 주고, 스트릭·타이머·알림·회고로 매일 나에게 투자하도록 동기를 주는 개인용 자기계발 앱. 모든 데이터는 내 휴대폰 안에만 저장된다.

**슬로건**: "As you thinketh, so you become"

## 대상 사용자

- 개인 한 명. 계정·서버·클라우드 동기화 없음 — 기기 안 암호화 DB, 앱 잠금(PIN)으로 타인이 보지 못하게 한다.
- 가족/팀 공유 개념 없음. 기기를 바꿀 때는 내보내기/가져오기 파일을 사용한다.

## 해결하려는 핵심 문제

1. **시간이 흘러가는 감각이 없다** — 하루를 쓰고 나면 얼마나 의미 있게 썼는지 알기 어렵다.
   → "버려진 시간/금액 vs 나의 시간/금액"을 실시간으로 보여 주는 Time 탭(F-21), 기간별 시간당 비용(F-24).
2. **꾸준히 이어 가기 어렵다.**
   → 스트릭·일일 목표·프리즈(F-26), 실시간 타이머(F-27), 손실 회피 알림(F-28), 마일스톤·보상(F-30). 지난 날은 확정되어 고쳐 쓸 수 없어(F-34) 기록이 정직하게 쌓인다.
3. **무엇에 투자했는지, 어떤 가치가 쌓이는지 보이지 않는다.**
   → 태그·복리 환산·통계(F-29), 회고(F-31), 홈 화면 위젯(F-32).

## 핵심 가치

- **내 데이터는 내 폰에만**: 서버 없음, DB 암호화, 앱 잠금, 비밀번호로 암호화한 백업.
- **즉각적인 보상감**: 숫자가 실시간으로 올라가는 타이머, 스트릭, 배지.
- **조용한 알림**: 모든 알림은 항목별로 사용자가 켠다(기본 꺼짐).

## 스코프 밖 (하지 않는 것)

- 서버 동기화·클라우드 백업·소셜 기능·계정 로그인
- 지도, 카메라/사진, 이미지 카드 생성·저장
- 문구·확언 관리, 목표/다짐/열망 (제거됨)
