> 표기: ✅ 현재 코드에 있음 / 📝 계획(v2, 코드 미반영). 결정 근거는 decisions.md D-233~D-254.

## 전체 구조 (Expo Router)

```
app/
├── _layout.tsx                루트 Stack. 📝 잠금 상태 확인 후 lock/(tabs) 분기. modal 프레젠테이션 라우트 등록
│
├── lock.tsx                   📝 앱 잠금 화면(PIN/생체인증, F-23) — 잠금 상태면 모든 화면 위에서 표시
│
├── (tabs)/                    하단 탭 (📝 3개: Time · 통계 · 설정)
│   ├── _layout.tsx
│   ├── time.tsx               ⏱ Time (F-21, F-24, F-26, F-27)
│   ├── stats.tsx              📝 📊 통계 — 요약/마일스톤/회고 (F-29~F-31)
│   └── settings.tsx           ⚙ 설정 (잠금, 나의 시간, 알림, 백업)
│
└── modal/                     presentation: 'modal'
    ├── time-log.tsx           ✅ 오늘의 의미있는 일 기록(제목/내용/시간) + 최근 3일 목록. 📝 태그 선택 추가(F-29)
    ├── time-settings.tsx      ✅ 나의 시간 설정 — 📝 기간별 시간당 비용 목록·추가·수정(F-24)로 전면 교체
    ├── timer.tsx              📝 실시간 타이머 진행 화면(F-27)
    ├── reflection.tsx         📝 오늘의 한 줄 회고 시트(F-31) — 알림/통계 탭에서 진입
    ├── backup.tsx             📝 내보내기/가져오기(F-25)
    └── db-recovery.tsx        📝 DB 열기 실패 안내(백업에서 가져오기/새로 시작, D-253)
```

## 화면 전환 흐름

```
앱 실행
  → 시작 순서: 폰트 → 잠금 상태 → DB 열기. 끝나기 전에는 스플래시 유지
  → (최초) PIN 설정 → Time (비용 기간 미등록이면 빈 상태 → 설정에서 등록)
  → (이후) lock(PIN/생체인증) → DB 열기 실패 시 안내 화면(D-253) → 일 단위 확정(D-251) → (tabs)/time
  → 백그라운드 30초 후 복귀 시 lock 재표시

(tabs)/time
  ├── 한 화면 유지(스크롤 없음, D-245): ① 맨 위 한 줄 — 스트릭 · 프리즈 · 일일 목표 진행률 (F-26)
  ├── ② 오늘 카드: 나의 시간/금액(+연필), 버려진 시간/금액, 오늘의 손익(F-28), 적용 중 시간당 비용
  ├── ③ 남은 카드: 진행바, 남은 일수, 남은 금액
  ├── "나의 시간 시작" 버튼 → modal/timer (F-27) → 정지 시 기록 저장
  ├── (지난 일수/지난 나의 금액/지난 버려진 금액은 통계 탭 "누적 현황"으로 이동)
  ├── 연필 아이콘 → modal/time-log
  ├── 지난 날 기록은 읽기 전용("이미 확정된 기록입니다") — 당일만 추가·수정·삭제(D-250)
  └── 비용 기간 미등록 시 빈 상태 → "나의 시간을 등록해주세요" + 설정 바로가기, 기간 종료 시 "새 기간을 추가해주세요"

(tabs)/stats  📝
  ├── [요약] 누적 현황(지난 일수·금액, D-245), 복리 환산(가정 수익률), 태그 도넛, 주/월 추이, 요일별 막대
  ├── [마일스톤] 누적 나의 금액 진행, 배지, 보상 문구 편집
  └── [회고] 날짜별 회고 목록 → modal/reflection

(tabs)/settings
  ├── 프로필 카드 대신 앱 잠금 설정: PIN 변경, 생체인증, 자동 잠금 시간 (F-23)
  ├── "Time" 그룹: "나의 시간" → modal/time-settings (기간별 비용, 하루 가용시간, 활동 시간대, 일일 목표, 스트릭 기준, 복리 가정 수익률)
  ├── "알림" 그룹: 손실 알림(오전/오후/저녁), 취침 전 회고, 마일스톤 접근 — 항목별 켜기/끄기, 기본 꺼짐 (F-28)
  ├── "위젯" 그룹(Android): 위젯에 금액 표시 켜기/끄기, 기본 끔 (F-32)
  └── "백업" 그룹: 내보내기/가져오기 → modal/backup (F-25)
```

## 탭 구성

| 탭 | 아이콘 | 화면 | 관련 기능 |
|---|---|---|---|
| Time | 시계 | time.tsx | F-21, F-24, F-26, F-27, F-28 |
| 통계 📝 | 막대그래프 | stats.tsx | F-29, F-30, F-31 |
| 설정 | 톱니바퀴 | settings.tsx | F-23, F-24, F-25, F-28, F-32 |

> 현재 코드(✅)는 Time · 설정 2개 탭이다(목표 탭은 삭제됨). 로그인 화면은 단계 0 조각 2에서 삭제하고 통계 탭은 단계 2에서 만든다(D-240).

## 딥링크 / 특이사항

- 스킴 `thinketh://`. 위젯의 "시작"은 `thinketh://timer`로 타이머 화면을 열기만 하고, 상태를 바꾸는 동작은 앱 안의 확인을 거친다(D-243, D-244).
- 알림을 누르면 알림 종류에 따라 Time 탭, 회고 시트(`modal/reflection`), 마일스톤 화면으로 이동한다.
- 잠금 상태에서는 어떤 딥링크·알림으로 들어와도 먼저 lock 화면을 거친다.
- 모달은 항상 최상단에 표시된다(Expo Router `presentation: 'modal'`).
